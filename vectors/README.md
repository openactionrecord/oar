# Test vectors

Every OAR verifier must reach the expected result on every case in `manifest.json` and `compat/manifest.json`.
The TypeScript reference verifier, the standalone WebCrypto verifier and the Python verifier all run them in CI.

- `manifest.json`: cases generated by `pnpm vectors` (deterministic; `scripts/vectors.ts`).
- `compat/`: records written by the first implementation, under the format's earlier name (AAR 0.3,
  `aar-evidence/0.1`). Verifiers must keep accepting them.
- `test-tsa-roots.json`: the root of a **test** timestamp authority. Pass it as the accepted roots for cases with
  `"tsa_roots": "test"`. It must never be trusted outside tests.

All keys here are **test keys**, published on purpose. Never use them for anything real.

Each case lists `expect.result`, and where relevant `level`, `failedChecks` and the `outcomes` of the actions in
the bundle.
- `compat/tridris-evidence-*.json`: real evidence packages exported by the Tridris product, which writes OAR
  records and re-salts each record's commitments. Records of one action are grouped by `decision_ref`.
